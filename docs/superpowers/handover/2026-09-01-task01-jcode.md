# Task 01 schema handover

## Scope

This handover covers only the remaining Task 01 verification gap found on 1 September 2026. The governance/audio models and Alembic migration already exist in the shared repository. The focused schema test was only a smoke test, so it did not exercise the required database constraints.

## Changes in this handover

- Expanded `starter/backend/tests/test_governance_schema.py` with real PostgreSQL fixture coverage for:
  - one active consent grant per user and scope;
  - one audio object per contribution;
  - duplicate SHA-256 values across distinct contributions;
  - persisted verifier qualification;
  - positive reward amounts and contribution reward-rule snapshots;
  - reward-rule update/delete immutability errors.
- Extended `starter/backend/tests/test_migrations.py` to assert that `contributions.reward_rule_id` has a foreign key to `campaign_reward_rules`.
