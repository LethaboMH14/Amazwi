# AMAZWI model cards

Cards are generated from `amazwi_ml.evidence.generate_model_card`, never handwritten as winner claims. A missing manifest, licence, split policy, acceptance policy, run status, or artefact hash raises `IncompleteEvidence`.

Cards must state the exact candidate status, promotion decision, metrics, slices, hashes, intended and prohibited uses, consent/revocation limits, and limitations. Until a real ledger-backed run exists, cards must not claim a GPU run, deployment, alias change, or improvement.
