## THE THEME — you do not have to choose today

Lethabo asked to keep the ability to switch rather than commit. **That is now built:** `04_assets/themes/tokens.css` defines all five as `[data-theme]` blocks. Switching is one line:

```js
document.documentElement.dataset.theme = 'dusk';   // shweshwe | dusk | earth | ndebele | ink
```

**So the decision moves from "pick one now" to "pick one by Wednesday morning."** Build against tokens, never hex, and the choice stays open at zero cost.

**Three constraints that hold whatever gets picked:**
1. **`earth` ships regardless.** It is the Day theme and it is an accessibility requirement, not an aesthetic option.
2. **`dusk` is deck and splash only** — small text over a mesh gradient is a contrast fight you lose.
3. **`ndebele` is seasonal**, and if it is used the attribution is said out loud.

**For Sbu and Codex:** review the four grounds and pick three you would ship. Links below. Send the three back and Lethabo makes the final call from the shortlist.

**Sbu has Figma's free tier connected to Codex too** — so he can pull the same design-system variables (`04_assets/FIGMA.md`), reference the Foundations sheet, and push his own component work or screen refinements into the same file rather than a separate one. One file, two editors, both visible to each other. Coordinate in `BUILD_LOG.md` before either of you touches the same node — Figma's plugin API scripts are atomic per-call but not atomic *between* two people's calls, so a "who's touching Foundations right now" ping avoids overwriting each other's work.
